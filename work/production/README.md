# PRODUCTION FOLDERS (filled by the human during stage 08)

- references/    character sheets, location references and product photos to lock
- current-shot/  for the shot being checked: shot-<n>-first.png, shot-<n>-middle.png,
                 shot-<n>-last.png and transcript.txt (what is actually spoken).
                 Empty it before the next shot.
- edit-check/    screenshots of every on-screen text overlay from the edit + transcript.txt
                 of the final dialogue track

The QC kickoffs read these folders. Keep file names simple (no spaces).
