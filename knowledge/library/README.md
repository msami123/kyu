# LIBRARY

One deconstruction per file, named library-<short-name>.md, using
knowledge/deconstruction-template.md.

Suggested first set for the POC:
- 20 videos from the founder's TikTok account: the 10 best and the 10 weakest by relative
  performance (for contrast).
- 30 successful Saudi retail or e-commerce ads from TikTok Creative Center (Saudi Arabia filter).
- 3 reference AI films, including the Ballon d'Or Heist (The Blue Horizon, 2026).

Rules:
- Describe and analyse; never paste scripts, lyrics or long transcripts from other works.
- Section 12 (what transfers) is the most important section: write the abstract pattern in
  one sentence.
- Mark works that use real people's faces or third-party IP in section 14; the pattern can
  transfer, the faces and IP never do.
